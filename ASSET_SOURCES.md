# Asset sources

## Included

- Buildings, soldiers, wolves, trees, terrain and HUD frames are original procedural geometry and UI generated by the project source. No paid model pack is included. Version 0.2 adds distinct building silhouettes, environmental detail and hand-painted UI illustrations.
- Noto Sans Regular and Noto Serif Bold from https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf. License accompanies the fonts in Assets/Resources/Fonts/LICENSE.txt. Used for Vietnamese UI.
- `Assets/Resources/Art/UI/TitleVillage.png`: generated with the built-in image_gen tool on 2026-10-25, used as the actual title screen background.
- `Assets/Resources/Art/UI/MedievalIcons.png`: generated with the built-in image_gen tool on 2026-10-25 as a transparent 4 by 4 atlas, sliced into sprites at runtime for resources, buildings and military controls.

Row 2: medieval great hall with teal banner; cream cottage with terracotta roof; small golden wheat farm plot with fence; wooden storage warehouse with crates.
