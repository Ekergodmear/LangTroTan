# Unity Asset Inventory — Thanh Vân Tông / LangTroTan

Audit date: 2026-10-26. Author: Claude (handoff audit). Method: direct filesystem inspection of `Assets/`, `Packages/`, `ProjectSettings/`, plus a disk search of the user profile for 3D source files.

## 1. Headline finding

**The project contains zero imported 3D assets.** There are no `.fbx`, `.obj`, `.glb/.gltf`, `.blend`, `.prefab`, `.mat`, `.anim`, `.controller` or Shader Graph files anywhere in `Assets/`. Every building, tree, rock, mountain, character and animal is generated at runtime from C# (`GameObject.CreatePrimitive` cubes/cylinders plus small hand-coded meshes). No 3D model sources were found elsewhere on disk (user profile search, depth 4), no Asset Store cache exists, and Blender is not installed.

This is the root cause of the "low-poly prototype" look. Lighting, shaders or post-processing cannot fix it (see `XIANXIA_ART_DIRECTION.md` §7).

**Performance note.** The previous slice raised scene triangles from 18,249 (Built-in, before) to 1,012,763 (URP, after) with 315 visible renderers. That is about 55× more triangles for a scene that still looks low-poly. The meshes are generated per instance and are not shared, batched, LOD'd or instanced. GPU time is still low on the RX 6600M (0.76 ms median), but this approach will not scale to a full sect plus characters, and it is not mobile-safe.
